# Flyff Universe Electron Wrapper

An Electron-based wrapper for [Flyff Universe](https://universe.flyff.com), specifically optimized for the Valve Steam Deck.

## Features
- **Multiboxing**: Two isolated accounts via `WebContentsView`.
- **Automation**: Integrated auto-heal and auto-buff engine.
- **Gamepad Support**: Full controller support with WASD movement, mouse emulation, and customizable button mappings.
- **Macros**: Record and play back key sequences.
- **Quick Reference**: Integrated Monster List for level-appropriate hunting.
